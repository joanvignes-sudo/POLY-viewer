# POLY Viewer v0.6

Version publique expérimentale du viewer POLY.

Cette version contient les 12 chaînes C01–C12 du registre empirique actuel, avec :
- 86 relations ;
- valeurs mesurées et ND commentables ;
- sources cliquables ;
- vues chaîne + cerveau ;
- modes Observer / Étudier ;
- plein écran et mode lecture.

Les commentaires sont stockés localement dans le navigateur de chaque visiteur et ne sont pas encore synchronisés.
