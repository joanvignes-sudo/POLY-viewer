# Simulation exploratoire v0.15 — avant calcul

Utiliser les paramètres véhicule gelés en v0.14 et les sessions de test véhicule/agoniste déjà réservées. Pour chaque session avec probabilités finies de chaque côté sur tous les CSplus, simuler 256 agents libres par modèle, sans réutiliser leurs choix ni récompenses observés. Les probabilités exportées sont exprimées en pourcentage ; les diviser par 100, vérifier [0 ; 1]. Aucun oubli d'essai sans choix dans la simulation : chaque CSplus déclenche une décision ; rapporter l'écart avec la présence éventuelle de no-go réels.

Comparer méta-apprentissage normal et ablation v0.14 (incertitude zéro, taux négatif médian véhicule), Q initiaux 0,5. À chaque essai, tirer le côté selon la politique logistique, puis une récompense selon la probabilité du côté choisi ; la récompense modifie seulement les états suivants. Réutiliser les mêmes uniformes indépendants pour choix et issues entre modèles afin de réduire le bruit Monte Carlo ; graine fixe 15004 + index déterministe de session. Ne pas sélectionner les paramètres sur les résultats simulés.

À chaque inversion stricte de préférence, retenir les 20 essais précédents et suivants seulement si le bloc précédent et le bloc suivant possèdent au moins 20 CSplus. Score = fraction de choix de l'ancien meilleur côté sur les 20 essais suivants. Comparer ce score et le taux de récompense normal/ablation, agréger transitions→sessions→animaux sans traiter les agents comme animaux indépendants. Séparer véhicule et agoniste ; des différences de calendrier entre conditions ne sont pas une intervention simulée. L'ablation est notre perturbation algorithmique, non une reproduction de l'action biologique de l'agoniste.

Vérifier que le moteur simulé à événements imposés reproduit les probabilités du noyau v0.14. Consigner les états hors [0 ; 1] ; ne pas les borner silencieusement. Cette simulation est une extension exploratoire de notre reconstruction ponctuelle, sans estimation hiérarchique originale ni preuve émotionnelle.
