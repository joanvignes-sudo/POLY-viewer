# POLY 0.142.0 — Enquêtes, anatomie et preuves

[Ouvrir POLY](https://joanvignes-sudo.github.io/POLY-viewer/) · [Tous les travaux](https://joanvignes-sudo.github.io/POLY-viewer/simulateur/web/travaux.html) · [Notice de version](RELEASE_v0.142.0.md)

POLY relie structures anatomiques, observations et mécanismes dans un environnement de recherche. Les simulations synthétiques, les preuves expérimentales et les inconnues sont distinguées ; aucune validation clinique individuelle n’est revendiquée.

## Parcours

- [Enquête glucose–lactate / NMDA](simulateur/web/metabolic-network-lab.html) : 35 maillons, 42 relations, 13 parcours ; hypothèses, sources et épreuves conditionnelles.
- [Anatomie](simulateur/web/anatomy.html) : catalogue léger, atelier classique, rattachements, journal et lecteurs documentaires.
- [Expériences et preuves](simulateur/web/recherche.html) : observations, modèles et protocoles existants.
- [COGITATE](simulateur/cogitate/index.html) : dossier expérimental distinct.
- [Suivi des développements](simulateur/reports/BODY_CONVERGENCE_CHECKLIST_2026-10-28.md) : acquis, tests et limites ouvertes.

## Disponibilité

Les blocs HRA/références/squelette générés, séries de recherche locales, données réservées, correspondances et pièces jointes privées restent hors dépôt et hors site. Les lecteurs locaux sont identifiés dans le sommaire ; leur code et leurs méthodes sont conservés. La version publique de l’enquête n’essaie pas de charger les séries privées.

## Vérification et historique

Les tests de code, les vérifications de sources et l’émulation navigateur ne valent pas validation biologique ou mesure sur téléphone physique. Les délais intermittents historiques restent de cause inconnue.
