# POLY Viewer v0.5

Version publique expérimentale du viewer POLY.

## Publication GitHub Pages
- Publier ce dossier à la racine d'un dépôt public.
- Dans Settings > Pages, choisir "Deploy from a branch".
- Branche: main
- Dossier: /(root)

Le site est statique. Les commentaires sont stockés localement dans le navigateur de chaque visiteur et ne sont pas synchronisés.
