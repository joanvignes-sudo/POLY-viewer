# POLY Viewer v0.6.1

Version publique expérimentale du viewer POLY.

Cette version contient les 12 chaînes C01–C12 et simplifie la barre de contrôle :
- Observer
- Étudier
- Reprendre
- Boucle
- navigation étape par étape
- vitesse
- mode lecture
- plein écran

Les boutons redondants « Charger » et « Pause » ont été retirés.

Les commentaires restent stockés localement dans le navigateur de chaque visiteur.
