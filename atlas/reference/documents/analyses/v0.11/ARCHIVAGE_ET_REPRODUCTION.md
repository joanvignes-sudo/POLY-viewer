# Archive de recherche v0.11

Les résultats JSON, spécifications, textes sources et scripts sont conservés ici. Les deux archives de données d'origine se trouvent dans ../../donnees/v0.11 ; leurs empreintes sont suivies dans MANIFEST_ARCHIVES.json. Les ZIP volumineux sont conservés sur disque et exclus du Git local ; ils doivent être inclus dans toute sauvegarde complète de POLY. Les scripts ont été exécutés depuis le workspace Codex original, où work/emotionnel_v11 contient l'extraction des ZIP et work/research_dependencies contient SciPy. L'environnement exact figure dans runtime.json. Le contenu des données et code auteur est préservé dans les ZIP, avec leurs README et licences d'origine : Harkin/Naud CC-BY-NC, données Grossman CC0 selon la provenance fournie, Li/Luo CC-BY, données traitées respiration MIT selon Zenodo. Les sources article conservées servent à l'audit interne ; aucune publication de ces sources ni du chantier n'a été faite.
