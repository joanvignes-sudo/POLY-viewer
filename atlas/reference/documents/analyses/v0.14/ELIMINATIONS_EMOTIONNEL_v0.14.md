# Éliminations et pistes — v0.14

« Éliminé » signifie ici écarté comme résultat acquis dans cette passe, sans réfutation générale de la littérature.

| Proposition | Statut | Motif |
|---|---|---|
| Méta-apprentissage améliore Q statique dans notre test principal | Soutien conditionnel | Quatre animaux sur quatre ; gain parfois petit |
| Le gain est indépendant de l'état initial | Écarté comme acquis | CG79 perd le gain avec incertitude initiale 1 |
| Méta-apprentissage dépasse les habitudes simples partout | Écarté | Témoin choix précédent meilleur chez CG09 |
| Transfert neuronal universel après calibration causale | Écarté | Deux gains positifs, deux négatifs |
| Ablation simulée reproduit spécifiquement l'effet agoniste | Non soutenu par cette reconstruction | Dégradation chez les six DREADDs ; estimation originale différente |
| Signal humain précoce utilisable en temps réel | Non validé | Normalisation sur la fenêtre entière |
| Mapping brut humain vers comportement | Partiellement établi | Identifiants exactement concordants ; matrices chimiques sans IDs, horloge physique non vérifiée |
| Calibration courants vers concentrations reproduite | Ouvert | Poids et entraînement nécessaires absents des cinq fichiers bruts |
| Contraste 5HT universel de difficulté | Écarté comme acquis | Signes différents et prédiction améliorée chez deux patients seulement |
| Ces tâches mesurent directement une émotion | Non établi | Pas de mesure émotionnelle directe dans ces tests |
| Les quatre premiers axes sont clos | Non | Données, mappings et comparaisons restent ouverts |

Couplages survivants à tester : histoire → choix ; passé neuronal → baseline ; tâche/site/patient → signal estimé ; corps/respiration → cohérence décrite en v0.13. Aucun n'est annoncé comme mécanisme émotionnel universel. Le bilan v0.14 expose les nombres, les conventions et les prochaines vérifications.
