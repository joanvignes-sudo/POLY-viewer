# Complément humain S24 — audit et analyse exploratoire fixés avant calcul

Source : [Bang et al., Neuron 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7736619/) et [dépôt auteur](https://github.com/danbang/article-DA-5HT-perceptual-decision), commit 0105f91e14364a9849b87e6d1013529ef0dec54e. Conserver les cinq patients séparés ; P1–P3 constituent le groupe présenté ensemble par les auteurs, P4 est séparé dans leur analyse et P5 est enregistré dans le putamen plutôt que le caudé. Les contrôles comportementaux ne sont pas des sujets avec mesure chimique. Cette collecte complète les préparations disponibles, sans remplacer les données GABA–dopamine demandées à Uchida ni créer une conception.

Auditer les trente matrices neurochimiques (DA, 5HT, PH × stimulus/décision × cinq patients) : dimensions, valeurs non finies, correspondance des comptes d'essais, moyenne/écart-type par ligne, doublons exacts, ordre des onsets et identifiants comportementaux. L'ordre des lignes est une convention du code auteur, sans identifiant explicite de trial dans les matrices chimiques. Vérifier les SHA256 et Git blob SHA1 des fichiers téléchargés. Les matrices sont des sorties estimées/normalisées ; elles ne sont pas les courants bruts ni des concentrations absolues en nM.

Reproduire les exclusions et le lissage de Figure3 : log RT, moyenne ±3 écarts-types (ddof=1), premier/dernier essai exclus, fenêtre causale de cinq samples. Aucun choix de temps selon significativité. Contraste principal exploratoire fixé : moyenne entre 0 et 0,8 s après stimulus moins moyenne entre −0,5 et 0 s, temps selon l'axe du script (sample MATLAB 11 = zéro). Calculer haute−basse cohérence pour les trois analytes, par patient. P5 n'a que 0,8 s de stimulus ; garder ce même intervalle pour tous. Ne pas compter les bins ou essais comme patients indépendants. Aucun p de population ; le contraste n'est pas une réplication des tests de chaque bin publiés.

Comparer ensuite, dans chaque patient, des prédictions rétrospectives du score chimique DA/5HT sur essais ultérieurs : temps/constante ; +cohérence ; +distance et interaction. Cinq blocs d'entraînement croissant (50 % puis 10 % supplémentaires), ridge λ=1 sauf constante, standardisation sur entraînement seul. Exclusion RT estimée sur la partie entraînement de chaque bloc ; premier/dernier essai exclus. Les scores chimiques sont normalisés sur la fenêtre entière de chaque essai ; ils ne peuvent pas être décrits comme un signal disponible en temps réel. La distance n'est présentée au patient qu'après le stimulus ; sa présence est une covariable rétrospective, pas un mécanisme d'anticipation démontré. Rapporter erreurs quadratiques et gains par patient, sans pool inférentiel. La normalisation et l'estimation électrochimique ne sont pas refaites depuis le brut.

Audit du code statistique : documenter la différence éventuelle entre intercepts préparés dans le script, arguments réellement passés à glmfit et méthode décrite dans le texte. Ne pas déclarer la publication invalidée : demander la version utilisée si nécessaire. Les résultats de contexte médical restent des descriptions de la préparation, aucune recommandation clinique.

Amendement d'audit après première lecture, avant résultat des contrastes : certaines matrices contiennent des samples non finis. Ne pas les remplacer par zéro pour produire un score. Le lissage nécessite cinq samples finis dans sa fenêtre ; les scores non finis sont exclus et comptés séparément après les exclusions comportementales. Les statistiques de normalisation sont calculées sur lignes entièrement finies. L'équivalence au lissage auteur est vérifiée en conservant les mêmes positions NaN. Aucun déplacement de la fenêtre pour récupérer un résultat.
