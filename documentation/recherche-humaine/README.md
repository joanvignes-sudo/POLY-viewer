# POLY — recherche humaine, 17 octobre 2026

Ouvrir **CATALOGUE.html** pour consulter les 18 fiches dans un navigateur. Aucun serveur ni installation n’est nécessaire.

- RAPPORT_RECHERCHE.md : synthèse, priorités, limites et fiches sourcées.
- SOURCES_HUMAINES.json : registre détaillé, niveaux de lecture, recoupements de cohortes et présence locale.
- SOURCES_HUMAINES.csv : tableau pour filtrer les publications.
- JOURNAL_RECHERCHE.json : démarche, termes consignés, incidents et exclusions.
- CONTROLES.json : résultats des contrôles locaux et de conservation.
- MANIFESTE.json : empreintes du supplément, hors manifeste lui-même.
- verifier.py : vérification locale reproductible, sans accès réseau ni modification des livraisons précédentes.

Depuis ce dossier : `python verifier.py`. Le contrôle de conservation nécessite les dossiers POLY locaux nommés dans le script. Le catalogue et le rapport restent lisibles sur un autre ordinateur.

Les 13 références complémentaires concernent l’extension du lecteur C13/FILMS ; deux étaient déjà repérables dans le registre général. Ne pas les présenter toutes comme nouvelles pour tout l’historique POLY. Cinq références du catalogue sont déjà représentées dans le lecteur.

Aucune donnée expérimentale inventée, aucune nouvelle expérience humaine, aucune modification du lecteur. Les études et leurs limites sont recensées ; aucune nouvelle analyse de leurs données ni validation scientifique de POLY n’a été effectuée.
